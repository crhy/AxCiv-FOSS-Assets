# Standalone data and art sources

The standalone pack is intended to contain no files from a commercial
Civilization II installation.

- `RULES.txt` and `CITY.txt` are generated and adapted from Freeciv's `civ2`
  ruleset at commit `94beba8bc7d6512e485ae35103bdb8fb55babb4f` by
  `scripts/import_freeciv_rules.py`. Freeciv is licensed under GNU GPL version
  2 or, at the recipient's option, any later version. The generated adaptations
  are distributed with rhYciv under GNU GPL version 3.
- Compatibility sprite sheets are generated by
  `scripts/build_standalone_sheets.py` from the individual art in
  `RaylibUI/FOSSart`. They are layout adapters, not copies of the original
  commercial sprite sheets.
- Citizen portraits and other custom textures were created for rhYciv and are
  stored as transparent PNGs in `RaylibUI/FOSSart`.
- C-evo-x commit `8e2e203e7766bc5524e989137b00d110a517238d` is a
  public-domain fallback source for assets still listed in the standalone
  audit. No C-evo file is currently copied into this directory.

Freeciv source: <https://github.com/freeciv/freeciv/tree/main/data/civ2>
